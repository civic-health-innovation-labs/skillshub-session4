The data

NORTHSTAR is a fictional study of adults admitted to three hospitals with a new respiratory virus. The REDCap export has 100 records and 102 fields. Every name, NHS number and value is invented. The study will link the cohort to national mortality data to find deaths after discharge, and the linked, versioned dataset will live in a TRE.

You do not need to open the data to answer the questions. If you want to look:

  • NORTHSTAR_redcap_export.csv (the export: 100 records, 102 fields)
  • NORTHSTAR_data_dictionary.csv (what each field means)
  • Original source: the DASC513 course data repository
The three layers
Bronze
As received, de-identified, read-only, never edited
Silver
Harmonised: formats, codes, standards. Every change logged with a count
Gold
Linked, versioned, documented; where data may also be put into a common format such as the OMOP Common Data Model. Projects apply for a subset
Abbreviations in the data

Obstructive sleep apnoea
CPAP
Continuous positive airway pressure, a breathing machine

Cerebrovascular accident (a stroke)
OD · BD · PRN · INH
Once a day · twice a day · as needed · inhaled
CRP
C-reactive protein, a blood test for inflammation, in mg/L
LSOA
Lower layer super output area, a small statistical area of about 1,500 people

Part C · problem 1 of 2 gold

Linking to mortality data on NHS number

A valid NHS number has 10 digits, and the last is a check digit calculated from the first nine. Every NHS number in the export was checked. Two fail.

RecordSiteNHS numberProblem
31Calderbrook999 123 456Nine digits, with spaces
72Mersey General9991234567Ten digits, but the check digit is wrong
Show the code that produced this
def valid_nhs_number(value):
    digits = str(value).replace(" ", "")
    if len(digits) != 10 or not digits.isdigit():
        return False
    total = sum(int(d) * (10 - i) for i, d in enumerate(digits[:9]))
    check = 11 - total % 11
    check = 0 if check == 11 else check
    return check != 10 and check == int(digits[9])

Which method, who does the matching, what happens to records 31 and 72, and what should be reported afterwards?
